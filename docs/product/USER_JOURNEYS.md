# User Journeys: TestReason

---

## 1. Critical User Journey (CUJ-1): Daily Learning Loop (Highest Priority)

```text
[Open App]
    ↓
[Home Dashboard]
    - See "Today's Recommended Study Plan"
    - Tap "Start Daily Quiz" (1-tap entry)
    ↓
[Quiz Question Screen]
    - Read JSTQB FL Question & 4 Choices
    - Select Choice
    - Select Confidence (Guess / Low / Medium / High)
    - Tap "Submit Answer"
    ↓
[Answer Evaluation & Explanation Screen]
    - Instant Correct/Incorrect Feedback
    - Correct Choice Explanation
    - Incorrect Choices Distractor Analysis (Why each other choice is wrong)
    - If Incorrect: Select Mistake Reason Tag
    - Tap "Next Question"
    ↓
[Session Result Screen]
    - Score & Confidence Distribution Summary
    - Learning Objective (LO) Mastery Delta
    - "Recommended Next Action" CTA (e.g., "Review Weak LO: FL-2.1", "Start Next Chapter")
```

---

## 2. Secondary Journey (CUJ-2): Target Weakness Review

```text
[Home / Analysis Screen]
    ↓
[Weakness Analysis View]
    - Filter by LOs with Mastery < 60%
    - Tap "Start Reviewing Weak LOs"
    ↓
[Targeted Review Session]
    - Questions prioritized by past mistake reasons and confidence level
    ↓
[Mastery Updated Feedback]
    - Visual feedback showing LO mastery recovery
```

---

## 3. Tertiary Journey (CUJ-3): Full Mock Exam

```text
[Home Screen]
    ↓
[Mock Exam Launcher]
    - Read Exam Rules (40 questions, 60 minutes timer, pass mark 65%)
    - Tap "Start Mock Exam"
    ↓
[Timed Exam Session]
    - 40 Questions, Flag for Review, Navigator Drawer
    - Submit Exam or Auto-submit on Timer Expiry
    ↓
[Mock Exam Results]
    - Pass/Fail prediction, LO Breakdown, Detailed Review Mode
```
