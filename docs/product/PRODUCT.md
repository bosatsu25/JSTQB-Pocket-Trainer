# Product Specification: TestReason

Product Name: **TestReason** (Repository: `JSTQB-Pocket-Trainer`)

---

## 1. Product Vision & Purpose

**TestReason** is an intelligent, offline-first mobile learning application for individuals preparing for the **JSTQB Foundation Level** (Japan Software Testing Qualifications Board) certification exam.

### Core Philosophy
> **TestReason is not merely a question bank. TestReason is a learning system.**

Simple question banks focus on repeating questions until memorized. TestReason focuses on **deep understanding**, **mistake analysis**, **spaced review**, and **mastery tracking**.

---

## 2. Target Audience & Personas

- **Primary Persona**: Software Engineers, QA Engineers, and Testers preparing for the JSTQB Foundation Level exam in Japan.
- **Needs**:
  - Efficient study during short commute/break times ("pocket trainer").
  - Clear explanations not just for why the correct option is right, but why each incorrect option is wrong.
  - Automatic tracking of weak areas linked directly to JSTQB Syllabus Learning Objectives (LO).
  - Clear indication of "What should I study today?" immediately upon opening the app.

---

## 3. Product Pillars

1. **Critical Learning Loop**:
   - Seamless flow from Home -> Quiz -> Answer -> Confidence Rating -> Detailed Explanation -> Mistake Classification -> Result & Recommended Next Action.

2. **Mastery & Learning Objective (LO) Tracking**:
   - Progress is measured by **Mastery Level** (understanding of concepts), not just raw correct answer percentage.
   - Maps questions directly to JSTQB Foundation Level Syllabus LOs (e.g., FL-1.1.1, FL-2.1.2).

3. **Spaced Review Engine**:
   - Automatically calculates review schedules based on user confidence, past attempts, and mistake reasons.

4. **Realistic Mock Exam Session**:
   - 40-question timed exam mode reflecting actual JSTQB FL exam conditions.

---

## 4. Key Differentiators

- **Confidence Assessment**: Users rate their confidence (Guess, Low, Medium, High) when answering, distinguishing lucky guesses from true mastery.
- **Mistake Reason Tagging**: When a user answers incorrectly, they can tag the reason (e.g., "Misread Question", "Terminology Confusion", "Concept Not Understood").
- **Next Action Orientation**: Every screen concludes with a clear, actionable recommendation on what to learn next.
