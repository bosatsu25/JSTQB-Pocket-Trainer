# UX Principles: TestReason

---

## 1. Zero Friction to Start Learning
- Users open the app to study in short time windows (train rides, short breaks).
- Home screen MUST present a primary call-to-action ("Start Today's Quiz") accessible within **1 tap**.
- Avoid multi-step dialogs or mandatory configuration screens before starting a practice session.

---

## 2. Deep Understanding over Speed
- UI must encourage deliberate reading and confidence assessment.
- Choice items must be distinct and comfortable to read (sufficient typography contrast and line-height).
- Explanations must clearly separate:
  - **Core Explanation**: Why the correct choice is right.
  - **Distractor Analysis**: Why each other option is wrong.

---

## 3. Action-Oriented Feedback
- Never leave the user at a dead end after completing a quiz or viewing analytics.
- Every result view MUST present a clear "Recommended Next Action" button (e.g. "Review Weak Area", "Retry Incorrect Items", "Continue Chapter").

---

## 4. Material 3 & Adaptive Design
- Follow Material Design 3 guidelines (Dynamic Color, M3 Cards, Buttons, TopAppBars).
- Adapt layout gracefully to portrait phones, foldable unfolded states, and large screens/tablets using window size classes or adaptive layouts.
- Dark theme support must be native and visually cohesive with high legibility.
