# UX Review Skill

Use this skill when implementing or reviewing UI screens and Compose components.

## UX Verification Checklist

1. **Frictionless Entry**:
   - Is the primary study action accessible within 1 tap from Home?

2. **Explanation Clarity**:
   - Are correct choice reasons and distractor analyses clearly separated?

3. **Next Action Orientation**:
   - Does the screen end with an explicit, actionable next step?

4. **Accessibility (a11y)**:
   - Are touch targets at least 48dp x 48dp?
   - Do interactive elements have `contentDescription` / TalkBack semantic properties?
   - Is font scaling up to 200% supported without text clipping?
